# Online rooms 2.0.6

Date: 2026-09-12. Android version code: 28.

## User flow

Select VS or Co-op, open the room browser, then create a named room or select a waiting room and join. A room may require an optional 4-64 character password. Two players start through the existing readiness/countdown flow. The browser automatically refreshes every eight seconds and supports manual refresh, empty/error states, masked password retry and Android Back navigation.

This is a player-room directory on the existing central server, not a fabricated list of regional dedicated servers. Quick matchmaking remains available separately. Only compatible rooms for the selected mode/build are listed, at most 100 per response. Legacy code-based/quick-match rooms are not public directory entries.

## Server behavior

- Directory: `GET /aksoy-tank/rooms?mode=online_vs&build=2.0.6`.
- WebSocket create/join actions: `create_room` and `join_room`. Existing `join`/`matchmake` messages remain supported, but cannot bypass managed-room password checks.
- Names are sanitized and limited to 24 characters; room codes are generated by the server.
- Public listing uses an explicit whitelist: room name/code/mode/occupancy/password-required/started status. No password, hash or reconnect token is returned.
- Passwords are verified using PBKDF2-HMAC-SHA256 with random per-room salt and 120,000 iterations, executed off the event loop. Hashes live only in server memory. The client keeps the password only in memory for transport reconnection, never in settings.
- Started rooms accept only an existing player's secret reconnect token, and cannot assign an already occupied slot. A new player receives a new token. Tokens survive host migration while the room remains alive.
- Join attempts are bounded to 60 per minute per address, with bounded/expired counter storage. Forwarded client addresses are accepted only from the explicitly configured internal proxy subnet. The relay port is not published to the internet.
- Last-player departure deletes room options/hashes/tokens. If both clients leave, the room is gone; this is not persistent match hosting.

## Remaining limits

No multi-region hosting or concurrent-room capacity certification is claimed. Play Console upload remains a separate manual action.
